下载和解压

关于网盘的选择
本站分享链接以百度网盘为主。你可以骂他垃圾限速，但也很难找到空间大、普及广（几乎人手必备）、分享资源不容易被和谐（这个很重要！）的网盘。众口难调，我也只能尽力把下载人数多的软件上传到夸克、迅雷网盘。其余的，实在没精力维护，只能以百度网盘分享为主。主流网盘下载速度都很慢，如果希望下载速度达到带宽上限，那就只能充值它们的会员。当然这只是建议，您开通网盘会员与本站没有任何关系。
网盘解压要钱？
禁止在网盘在线解压！请先将文件下载到电脑上，再使用电脑里的压缩软件解压。
为什么压缩包有解压密码？
防止网盘和谐，防止有人无脑搬运售卖。绝对不是为了收您的钱！因为解压密码是公开的↓↓
解压密码是什么？
解压密码：ruancang.net
解压失败或密码错误？
本站分享的文件仅有唯一解压密码 ruancang.net ，如果使用该密码仍然提示解压错误，实际是下载的文件出错了。下载大文件有一定几率出错，可尝试使用 WinRAR 压缩软件自带的「工具 - 修复压缩包」功能修复报错的压缩包，将修复出来的压缩包替换错误压缩包后即可解压。或者干脆重下一次，用单线程下载可以大幅降低坏包几率。
解压后找不到 xx 文件？
这种情况一般是被 Windows 电脑自带的杀毒软件 Windows Defender 误删。判断办法：打开下载的压缩包不要解压，用压缩软件查看里面是否有 xx 文件，如果压缩包内有、解压出来后没有，那就是被误删了。解决办法：安装 火绒 自动接管 Windows 杀毒；或 查看教程手动关闭 Windows Defender。
