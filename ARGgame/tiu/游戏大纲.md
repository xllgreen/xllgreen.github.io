## 一、游戏概念

玩家扮演 TIU 的朋友/同学「**暮鸢**」，浏览"南方农业工程学院科联官网"，发现网站不对劲：三下乡队伍提前返程、考勤记录中断、有不该存在的页面。玩家通过**站内搜索框**输入关键词，解锁隐藏页面，一步步查明 TIU 在"青云村科技支农"三下乡期间失踪的真相。

- 玩法核心：阅读页面 → 找关键词 → 搜索 → 解锁隐藏页 → 循环
- 页脚页码 X/36 即进度条（数字越大越接近真相）
- 游戏时长目标：完整版 30 分钟 ~ 1 小时
- 全程站内闭环，**不依赖外部搜索**（虚构公司搜不到）
- **开场**：intro.html（2026-08-21 新增）——虚构声明 + 暮鸢视角剧情导入 + 目标一二 + 玩法提示 + 「开始游戏」→ index.html；index.html 另有首访免责遮罩（localStorage `tiu-intro-seen`）兜底直接访问者

### 反转设定 · 邪教献祭（2026-08-21 改版 v2 新增）

**表层真相（玩家一路以为的）**：禾丰骗补 186 万 + 非法拘禁——17~34 页证据链全部保留。

**深层真相（verdict 38 揭晓）**：禾丰部分人员与青云村个别村民背后存在一个邪教组织，以"示范点"为名圈定村西场地（仓库 + 老井），借"落成庆典"之名筹备献祭仪式。**TIU 被控的真正原因：他是仪式所需的外乡祭品**——年轻、外乡、07-19 独自走进仓库。

- 献祭日 = **07-28**（与救援日重合）：07-19 抓获 → 待祭期关押至 07-28 夜 → 07-26 凌晨的"8 分钟后台编辑"正发生在这段待祭期内；07-21 提前返程的深层原因是仪式前清场
- 仪式地：村西老井（图 23 手绘地图已有"老井"二字 = 现成伏笔位）
- 救援为什么能赶上：07-28 04:30 出发 → 07:40 抵达 → 07:52 破门；仪式定于 07-28 深夜（借"落成庆典"之名）——救援在仪式前赶到，ending 以"你们要是晚来几个小时——"回收
- 反转节奏：全程不点破超自然词汇（"邪教""献祭"在 verdict 之前不出现在任何页面），rescue 的祭坛物证以"现场记了'疑似祭祀用品'"呈现（人物不解），保反转

### 故事逻辑 · 完整因果链（2026-08-11 整理，所有页面必须与此一致！）

**起因（2019—2026）**：禾丰以"智慧农业示范点"名义虚报项目。青云村 20 套"监测设备"全是空壳机箱，数据由人工批量改写，靠假验收骗取省级专项补助累计 **186 万元**。示范点需要"校企合作"背书——于是有了 2026 年与科联的合作。

**发现（07-16~07-18）**：设备安装时 TIU 蹲在机箱边看了三天（hf-log 07-16："问了很多问题"）。他性格较真、爱记录，觉得数据"漂亮得不真实"。

**确认（07-19 上午）**：公司临时安排参观示范点（早于行程表一天）。TIU 注意到指示灯不亮、机箱是空的——草稿里写下"太漂亮了"。14:00 他回驻点写公众号草稿（"有件事我没写进稿子""下午，我打算去村西仓库，再确认一次"），随后动身。

**失联（07-19 下午）**：行程表当天是"入户走访（村西片区）"。TIU 借走 GPS（hard 设备台账）独自去村西仓库核对备件清单。**14:32** 他走进仓库被控制：手机被收、GPS 离线、考勤中断。他的失联不能公开——公司不能让人知道"有人在查示范点"。

**掩盖（07-19~07-25）**：三步——① 当晚 23:47 起 TIU 短暂拿到网络（仓库电脑网线），向队友发微信求救（"他们没收了手机""记住这个位置"），随后账号被强制下线；② 07-20 公司删除下乡日志、删改考勤记录、停用 TIU 账号，施压队伍 07-21"因天气原因"提前返程（行程表 07/21 本是休整——表层矛盾点）；③ 07-22 返程签到 5 人（出发 6 人），TIU 未归；网传质疑后公司发"澄清声明"随即删除（statement 404 页）。

**留线索（07-20 凌晨）**：手机已被收走的第一个夜晚，TIU 在纸片背面写字条——"打印出来。别删除。""网站不会消失，记录不会说谎"，压在仓库键盘下（note 页）。

**被迫"整理数据"（07-20 起）**：赵经理让 TIU 用仓库旧电脑把示范点资料导进公司系统——把能上网的网线留在他"够得着的地方"。白天网线被拔，夜里接通。

**关键 8 分钟（07-26 02:17~02:25）**：TIU 登录科联后台，逐页改一笔——02:17 考勤、02:19 方案 V2、02:21 返程签到、02:23 草稿、02:25 GPS。每页留下自己的时间戳，"像在留言，又像在敲钟"。他不求救，赌朋友会发现页面"不对"。

**玩家介入（游戏时）**：玩家（TIU 的朋友/同学）发现官网异常（返程矛盾、考勤中断、签到缺人）→ 搜「禾丰」进入第二幕 → 挖出假设备/假数据/假合同 → 聊天记录与 GPS 交叉验证锁定**村西仓库 29.6320°N, 111.7410°E** → 活动安排表（25）与仓储领用清单（26）对不上 → 后台日志揭穿 8 分钟真相 → 证据整合（evidence）→ 报警 → 07-28 救援成功 → 禾丰被立案（probe）→ 现场勘验记录（site-record）→ TIU 归来（homecoming）→ 字条（note）→ 调查结果（verdict）→ 结局（ending）→ 通关后搜「失踪」→ 彩蛋（after 失踪档案）。

**结局（08-05）**：骗补 186 万、非法拘禁，赵志强（项目负责人、涉案组织头目）等 5 人被采取强制措施——5 人 = 赵志强 + 仓管保安 + 技术部人员 + 财务部负责人 + 跟单员（与 rescue 抓捕名单一一对应）。TIU 复课，网站被修好——但时间戳都留着，"像一排安静的脚印"。

## 七、技术约定

- 纯静态，file:// 可运行；无服务器依赖
- 搜索：search.html 用 md5.min.js 对关键词做 MD5+Base64 → 查 js/keys.js 的 `window.ENCRYPTED` / `window.FORBIDDEN`
  - **改 keys.js 必须保持 JSON 语法正确（逗号！）**，加词用 node 算哈希：
    `Buffer.from(crypto.createHash('md5').update(词.trim().toLowerCase(),'utf8').digest('hex'),'hex').toString('base64')`
- 图片位：`<figure class="photo" data-label="图片 XX · 待生成"><img src="images/XX.png" onerror="this.closest('.photo').classList.add('empty')">`——图缺失显示虚线占位，放图即生效；点击放大（app.js 灯箱）
- **图片布局规范（2026-08-11 定稿）**：
  - 所有 `<figure class="photo">` 必须放在 `.photo-grid` 内（`single` 单列居中 / 默认两图左右并排 / `wall` 多图紧凑换行）；banner 横幅图（01、20）除外
  - 每张图必须带 `<figcaption>` 注释；**注释只写场景说明**——不写"模糊/发虚/失焦"等字眼，**不提图内文字**（线索留给玩家点大图发现）
  - 尺寸：普通图 max-width 220px，手机截图（9:16）加 `class="photo phone-shot"` 限 180px；全部居中
  - 小屏 ≤900px 自动改为竖排堆叠
- 图片命名：images/01.webp ~ 42.webp（纯数字；发布版 WebP，压缩规格为最长边 1600、关键词图 q85/背景图 q75；40 页版新增 39 仓储清单/hf-material、40 活动安排/hf-schedule、41 现场勘验/site-record、42 门缝/ending，待用户生成）；原图 PNG 备份于项目根 backup_png/（不上传）；生成提示词见 images/图片清单.txt；压缩脚本 tools/compress-images.js
- 页码规则：页脚 `<strong>X/40</strong>`；search/statement 用 —/40；**新页面必须按顺序用下一个可用页码**
- 通用样式类：card / entry-card / tbl / page-band / two-col / prose / section-head / notice-strip / secret-note / redact(涂黑反选) / handwrite(手写体) / b.kw(加粗关键词) / photo / photo-grid
