# 《星河乐园（Galaxy Park）旧官方网站》玩家说明

## 启动方式

本作是纯静态网页，不需要安装数据库或登录现实账户。推荐在项目根目录启动本地静态服务器：

```powershell
py -m http.server 8000
```

然后使用浏览器打开 `http://localhost:8000/`。

推荐使用最新版 Microsoft Edge、Google Chrome 或 Firefox。直接双击 HTML 也可游玩，但部分浏览器会限制本地文件之间的下载和跳转，因此仍建议使用静态服务器。

## 无剧透说明

- 完整游玩通常需要 60 至 100 分钟。
- 网站内的“调查记录”会逐步记录已经遇到的问题；未发现的内容只显示为问号。
- 每个主要问题最多有三级提示。提示只在调查记录中出现，错误输入不会扣分或锁定账户。
- 部分步骤需要下载并阅读 PDF、DOCX、TXT 和加密 ZIP。另有 CSV 原始导出，但每份 CSV 都附有内容相同、可用记事本打开的 TXT。
- 加密 ZIP 使用兼容性较高的传统 ZIP 加密，建议使用 7-Zip、WinRAR 或系统支持的 ZIP 工具打开。
- 不需要查看网页源代码、开发者工具或脚本变量，也不需要暴力猜密码。
- 建议保留下载文件，并记录反复出现的日期、编号、附件序号和用词差异。

## 进度与重置

进度只保存在当前浏览器的 `localStorage` 中，不会上传。关闭页面后再次使用同一浏览器和同一网址进入，进度仍会保留。

可在开场说明页、调查记录页或结局后的感谢页清除进度。清除后无法恢复，下载到本机的附件不会被删除。

## 内容提示

故事包含完全虚构的未成年人研究、行为控制、记忆干预、隐私侵犯和政府档案隐瞒情节。

本作没有鬼怪、血腥图片、突然跳脸、闪屏、抖屏、大音量音效或自动播放音频，也不会申请摄像头、麦克风、位置等浏览器权限。
