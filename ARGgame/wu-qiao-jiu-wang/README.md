# 《第404楼：雾桥旧网》

纯静态网页悬疑解谜游戏，无需安装依赖或执行构建。玩家扮演暑期淘到旧电脑的大学生小周，从开机自检、密码登录和00年代桌面进入调查。

## 运行

直接双击 `index.html` 即可游玩。推荐 Chrome、Edge 或 Firefox 的较新版本。

部署到 GitHub Pages 时，把本目录内的全部文件上传到仓库根目录，确保根目录直接看到 `index.html`，Pages 选择 `main` 与 `/(root)`。

## 核心规则

- 点击“按下电源”会经历开机自检；登录密码可由机箱维修贴的“月日＋机号”推导。
- 调查记录簿和八个平台共九个程序均位于桌面；八个平台不再共用单一搜索模板，论坛、帖吧、博客、校友录、聊天、短信、邮箱和网吧后台分别拥有可点击的栏目与内容层。
- 天崖主题可进入楼层页，企鹅聊聊可按好友打开聊天记录，飞讯与壹陆叁可按文件夹打开短信、邮件、邮件头和附件说明；主题与文件夹数量按本机离线缓存规模设置。
- 浏览帖子、图片、搜索结果不会自动取得线索或推进章节。
- 调查记录簿统一使用“候选证据＋关键词填空/选择”：玩家仍需理解材料，但不会因中文同义表达、标点或技术字段拼写不同而判错。
- 共8个主线谜题、4条调查路线、12个档案场景和8种结局。路线谜题采用“选择证据组＋两个关系关键词”，不再要求连续抄写元数据或自由写理由。
- 单周目完成两条路线；四条路线的完成记录会跨周目保留。第二周目自动进入“档案续查”，继承前六章证据并排除已完成路线，用于S+结局。
- 照片鉴伪提供无人原图与后加红影传播图的并排版本，视觉差异仍需由文件链和年代记录验证。
- 蓝鲸后台表格、邮件头、缓存记录和结算索引均保留原始样式，同时提供默认展开的“小白判读卡”、列名翻译、关键行高亮和白话结论。
- 终章采用结构化事实、来源组、隐私和授权选项；公开摘要由选择自动生成，不再读取玩家自由表述。
- 秦禾、陆珂和胡南均有跨应用人物材料、矛盾动机与路线侧写，不以单一“好人/坏人”标签代替责任分析。
- Web Audio实时生成雨声、机箱低鸣、硬盘寻道与界面反馈，无需联网加载音频；顶部声音按钮可立即关闭全部声音。
- 三级提示全部免费，第三级给出当前页面的完整选择；路线提示会随玩家挂载的档案包变化。
- 1元支持为自愿打赏，不验证真实付款，不影响谜题、提示、章节或结局。

## 存档

进度自动保存在浏览器本机。设置中可以导出或导入JSON存档。清除浏览器网站数据会同时清除进度。

## 文件

- `index.html`：游戏入口
- `styles.css`：开机、登录、桌面、八种旧软件内容层、移动端与付款弹层样式
- `data.js`：八个平台搜索材料、路线、提示与结局数据
- `apps.js`：八个应用的栏目、主题、楼层、聊天、短信、邮件与后台内容
- `logic.js`：8种结局的结构化纯逻辑判定与报告校验
- `game.js`：流程、关键词选择校验、分支、存档、付款与设置逻辑
- `assets/`：写实场景图、照片鉴伪前后版本、2008年代桌面壁纸与收款码
- `release_check.js`：资源引用、路线填空、无自由文本判题、后台白话说明和8种结局校验
- `build_release.bat`：Windows一键执行语法与发布校验，并生成仅含本次修改文件的压缩包

所有平台、机构、账号、人物和联系方式均为虚构；平台名称使用谐音化表达，不对应真实服务。
