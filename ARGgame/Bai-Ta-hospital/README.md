# 白塔医院：零点交班（v4.1 完整发布版）

这是一个纯前端叙事解谜游戏，不需要服务器、数据库或构建工具。`index.html`、`css/`、`js/`、`assets/` 必须保持当前相对位置。

## v4.1 修改内容

1. **门户美术**：新增病房、检验科、挂号窗口、ICU、消防楼梯、病案复印窗口、护理培训教室和会议室；25篇文章改为17类场景，任一图片最多复用两次，并统一历史照片色调。
2. **揭示节奏**：旧版镜像只保留项目代号、匿名维护标识和人数版本差异，不再提前公布项目全称、对象性质、负责人和伦理结论。
3. **自主推理**：监控身份、日志责任链和最终报告改为自由填写，玩家需要自己概括观察结果和字段含义。
4. **图纸叠合**：取消坐标与缩放数值滑块，改为直接拖动、方向微调和视觉自动吸附；结构吻合后才显现B7-0边界。
5. **结局后续**：不同公开方式分别显示新闻报道、院方处置、幸存者回信和证据去向；完整隐藏链可进入B8-11结局。
6. **邮件因果**：补充2013年冻结队列、旧域封存和2026年服务器镜像恢复日志，解释邮件为何延迟十三年投递。
7. **自愿支持**：完成首个登录谜题后，页面连续停留3秒自动提示；手动打开过支持页后不会被自动计时重复打断。

## 上传 GitHub Pages

1. 先删除仓库中原有的站点文件，避免遗留旧版资源。
2. 解压发布包，把解压后看到的全部文件和文件夹直接上传到仓库根目录；不要再多套一层文件夹。
3. 仓库根目录应直接看到 `index.html`，并同时存在 `assets`、`css`、`js` 三个文件夹。
4. 在 GitHub 仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。
5. 发布后若仍看到旧页面，请等待 Pages 部署完成，再硬刷新浏览器（Windows：`Ctrl+F5`；macOS：`Command+Shift+R`）。

## Windows 一键校验与重新打包

双击 `build_release.bat`。脚本会检查 JavaScript 语法（电脑已安装 Node.js 时）、检查合并冲突标记，并在当前目录生成新的 `Bai-Ta-hospital-v4.1-complete.zip`。

若只需要重新生成本次增量更新包，双击 `build_update.bat`，会得到 `Bai-Ta-hospital-v4.1-update-only.zip`。

## 运行说明

- 推荐使用最新版 Chrome、Edge、Firefox 或 Safari。
- 进度保存在当前浏览器的本地存储中；清理站点数据会同时清除存档。
- 1 元支持为完全自愿，不付款也可完整游玩，页面不会验证真实支付。
- 游戏内医院、人物、项目和医疗事件均为虚构。
