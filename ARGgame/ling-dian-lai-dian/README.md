# 零点来电｜玩家反馈优化版

原创现实悬疑网页侦探解谜。当前版本结合网页ARG玩家常见好评与卡点做了体验收口。

## 核心内容
- 单页统一调查壳层，内部模拟多网站 ARG。
- 15 个核心推理节点，9 项终局事实链。
- 132 条论坛缓存，其中 8 条非主线城市/人物彩蛋。
- 8 名核心人物，7 条可独立完成的人物核验支线。
- 三级动态提示 + “调查方向”导航；方向只告诉玩家去哪里核验，不直接给答案。
- 搜索支持同义词/模糊方向（如“公话/电话亭/公用电话”“七码/T7/转接室”）。
- 新开放系统提供“新”标记，锁定系统明确显示开放条件，避免被误认为网页故障。
- “七码”“2003误播”“撒谎≠共同杀人”等核心概念会在推理成立后回收解释。
- 结局明确说明不同档案处理方式的代价，并补充主要人物后续。
- 隐藏结局条件在终局直接显示，不需要依赖评论区或外部攻略获知。

## 稳定性与无障碍
- 所有关键声音均有文字转录与波形替代。
- 图片加载失败会自动切换本地档案占位图；音频失败自动提示文字兜底。
- 不依赖真实邮箱、外部 API、远程图片或第三方脚本。
- 自动存档使用 localStorage，可导出/导入 JSON；兼容此前同键名存档的核心主线字段。
- PC / 平板 / 手机使用响应式布局。

## 运行
直接打开 `index.html`，或部署到 GitHub Pages / Cloudflare Pages 即可。
