# 晚舟堂：青溪旧事（水墨江南·写实人物肖像版）

一款无需服务器、无需安装依赖的民国乡土多结局网页解谜游戏。

## 本版重点

- 保留烟雨江南淡墨水彩场景与宣纸界面
- 将原来的色块占位头像替换为 5 幅民国江南写实人物肖像
- 林砚、林晚舟、苏婉、周满、老更夫均有独立头像
- 修复老更夫错误复用周满头像的问题
- 在家书真相节点显示林晚舟旧照，使历史人物真正进入叙事
- 人物头像会随章节、证词与真相节点自动切换
- 五章主线、九个逻辑谜题、三级免费提示和三种结局保持不变
- 保留自动/手动存档、便笺、线索板和 1 元自愿支持系统


## 2026-08-05 场景画面升级

- 重制晚舟堂药铺、废弃私塾、后山药庐和桂雨庭院四幅主场景。
- 保持原章节含义、交互位置和谜题逻辑不变。
- 新场景采用白墙黛瓦、木质室内、湿润窗光、细雨墨雾与宣纸颗粒。
- 使用新文件名避免 GitHub Pages 与浏览器继续读取旧图片缓存。

## 人物肖像说明

本作中的人物均为虚构角色。头像是为游戏制作的写实化艺术肖像，不是真实历史人物照片，也不对应现实中的特定个人。服装、发式、布光和旧照质感根据民国四十一年前后的江南小镇背景统一设计。

## 运行方式

直接双击 `index.html` 即可游玩，也可以把本目录全部文件上传至 GitHub Pages。

本项目不需要 BAT、PowerShell、Node.js 或构建工具。压缩包中的文件已经是处理后的最终文件。

## 文件结构

- `index.html`：页面结构和功能入口
- `styles.css`：基础布局、交互及人物头像样式
- `ink-style.css`：水墨江南视觉覆盖层
- `game.js`：剧情、谜题、人物头像切换、存档、提示、音效和结局逻辑
- `paywall.js` / `paywall.css`：1 元自愿支持模块
- `paycode.png`：支持二维码
- `assets/ink_*.webp`：水墨场景图
- `assets/portraits/*.webp`：五名角色的写实化虚构人物肖像
- `assets/brush-divider.svg`：水墨笔触分隔元素
- `CMD上传命令.txt`：GitHub 上传命令
- `评价与修改说明.txt`：本次评价及调整内容
- `测试报告.txt`：流程和 Bug 检查结果
- `人物肖像说明.txt`：人物美术设定与使用说明

## 浏览器建议

推荐最新版 Chrome、Edge、Firefox 或 Safari。浏览器要求玩家产生首次点击后才能播放声音，因此琴音、雨声和钟声会在点击“入堂启卷”后启用。

## 自愿支持说明

支持与游戏进度完全分离。不支持也可完整游玩五章剧情、查看全部三级提示并进入全部结局。点击“已完成支持”只在当前浏览器中记录感谢状态，不改变任何游戏内容。
