# 《2008届毕业照》网页解谜

纯静态 HTML/CSS/JS 网页游戏，可直接部署到 GitHub Pages、Cloudflare Pages 等静态托管。

## 本版重点

- 二维写实固定视角场景，核心流程不使用电脑桌面模拟。
- 所有场景热点默认不可见；鼠标经过不高亮、不改变光标，玩家自行观察与点击。
- 关键人物照片改为真实摄影质感，不再使用人物简笔图/符号化合影。
- 毕业合影可查看正反面；307照片对照使用同视角的2008教室快照，可拖动、缩放、旋转、调整透明度。
- 暗房显影、电话证词、实体纸质线索、线索册、三级提示、自动存档、3个普通结局+1个隐藏结局。
- 针对电脑与平板重新布局：1920×1080、1366×768、1180×820/1024×768 横屏，以及 820×1180/768×1024 竖屏均可操作。
- 平板竖屏下场景保持16:9，不裁掉关键热点；当前目标和环境信息自动移到场景下方的信息区。

## 运行与发布

双击 `index.html` 可本地试玩。Windows 用户可双击 `build_release.bat`：脚本会检查核心文件；若系统安装 Node.js，会执行 `node --check app.js`；随后生成 `release\2008届毕业照` 和 `2008届毕业照-release.zip`。

## 自愿支持入口

结局后保留 ¥1 / ¥3 / ¥6 自愿支持入口，但当前源码不包含作者真实收款码。若需要接入，请将二维码图片放入 `assets/img/` 并修改 `app.js` 中 `support(amount)`。
