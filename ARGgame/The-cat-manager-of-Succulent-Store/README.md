# 《窗台多肉铺的猫店长》修订版

轻治愈网页解谜养成游戏。玩家回到外婆空置三年的多肉铺，与左耳缺角的三花猫店长一起整理铺面、接待客人、修复后院花房，并重新理解“回来”和“留下”的意义。

## 本次修订重点

- 保留 12 章主线与暖色手绘素材，重做每章任务反馈和谜题可读性。
- 新增三级免费提示；提示与自愿支持完全分离。
- 取消章节中的自动支持弹窗，明确“不付款也能完整游玩”。
- 存档升级为 v2：兼容旧版存档迁移、深层数据合并、主存档与备份槽、手动保存、导入导出。
- 重新开店需要输入确认文字，避免误删进度。
- 增加章节路线、步骤状态、错误恢复、键盘焦点和移动端布局。
- 将收集目标调整为 32 种植物、24 项成就、12 个有明确触发方式的彩蛋，降低无意义堆量。

## 运行

直接打开 `index.html`，或将本文件夹全部上传到 GitHub Pages。存档保存在浏览器本地。

## 文件

- `index.html`：页面结构。
- `style.css`：游戏界面和响应式样式。
- `game.js`：12 章流程、提示、存档、图鉴、成就、彩蛋和设置。
- `paywall.js` / `paywall.css`：完全自愿的一元支持弹窗。
- PNG 文件：封面、猫店长、植物贴纸和收款码。
