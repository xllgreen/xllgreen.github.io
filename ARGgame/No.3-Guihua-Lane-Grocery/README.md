# 桂花巷三号杂货铺

静态网页互动解谜作品。

## 运行方式

直接打开 `index.html` 即可游玩。作品不依赖服务器，也不需要安装依赖。

## 文件说明

- `index.html`：页面入口
- `style.css`：主视觉与响应式样式
- `game.js`：五章谜题、存档、提示、多结局逻辑
- `paywall.js` / `paywall.css`：1 元支持弹窗，沿用潮汐福利院的前端标记方案并做本作适配
- `paycode.png`：收款码

## 已验证流程

- 第一章账本密码解锁留言墙
- 第二章便签排序解锁货架
- 第三章相册匹配、隐藏纪念物、收音机密码
- 第四章铁皮信箱密码与身份反转
- 第五章三种结局分支
- 三级提示记录
- 付款弹窗、收款码加载、已支持标记
- 桌面端与移动端基础显示
