# 暮光照相馆：未显影的第六张

温馨治愈照片修复叙事解谜网页游戏。

## 部署

将本文件夹中的 `index.html`、CSS、JS 与完整 `assets/` 目录上传到 GitHub 仓库根目录，然后在 Settings → Pages 中选择 `main / (root)`。

不要只上传压缩包，也不要遗漏 `assets`。

## 游玩与存档

- 直接打开 `index.html` 可以游玩；部分浏览器在本地文件模式下可能限制音频，建议使用本地 HTTP 服务。
- 存档、设置和“已完成支持”标记只保存在当前浏览器。
- 支持 100%、115%、130% 字号，高对比、减少动画、拖拽辅助、存档导入导出。
- 1 元支持属于自愿打赏，不扫码也能关闭并完整游玩。

## 主线

序章 + 六卷胶片 + 尾声；12 个谜题；四个常规结局 A-D；集齐六枚胶片标记可追加 S 尾声。

## docs 文件夹

`docs/` 仅包含测试截图、开发者答案与校验记录，不参与游戏运行。部署公开仓库时可以不上传；其中答案文件含剧透。
