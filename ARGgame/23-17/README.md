# 《23:17》

时间循环 × 自由文本行动 × 普通人生活恐怖网页解谜。

- 每轮：22:47 → 23:17，共30分钟。
- 常见中文优先在浏览器本地解析，不接服务器也能完整通关。
- 复杂表达可由 `worker/worker.js` 的 Cloudflare Workers AI 兜底；AI不掌握游戏真相。
- AI 默认4.5秒超时，超时立即回退本地规则。
- 三级渐进提示，按当前调查阶段解锁，并可随时回看历史提示。
- 浏览器 Web Audio 生成房间差异化环境音：电梯、脚步、门响、手机震动、管线、冰箱和天台风声，可关闭。
- 场景素材统一为1600×900发行规格，并做统一夜景亮度、色温和锐化处理。
- 存档使用 localStorage，并兼容旧 `game2317_save_v1`。
- PC / 平板 / 手机响应式布局。

## 构建

Windows 双击 `build_release.bat`。脚本会检查 `app.js`、`config.js`、`worker/worker.js` 语法，执行 `release_check.js`，再生成 `release` 与 `23-17-release.zip`。
